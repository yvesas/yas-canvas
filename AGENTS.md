# Instruções para agentes

Pack de skills de método para liderança técnica. **Leia [`CLAUDE.md`](./CLAUDE.md) primeiro.**

Três coisas que não se negociam:

1. **Skill propõe; hook enforça.** Nada aqui commita, abre PR ou faz deploy.
2. **O preâmbulo se lê, não se cola.** Uma fonte: `shared/preamble.md`.
3. **Sem atribuição de IA** em commit, PR ou comentário: nada de
   `Co-Authored-By`, "Generated with" ou assinatura de ferramenta.

`npm run check` antes de considerar qualquer coisa pronta.
