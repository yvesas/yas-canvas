# Conceitos

**Golden Circle** — porquê (a razão de existir, numa história concreta) → como (o jeito diferente) → o quê (o produto). Comunicar de dentro para fora.

**Usuário × cliente × pagador × decisor** — quem usa, para quem o problema é resolvido, quem paga, quem diz sim. Em B2B raramente são a mesma pessoa.

**Early adopter** — dentro do segmento, quem sente a dor mais forte, já tenta resolver e aceita produto imperfeito.

**Anti-persona** — o perfil que você não atende, descrito pelo sinal observável numa conversa ("só pergunta preço", "quer garantia de resultado").

**Jobs to be Done** — o cliente "contrata" um produto para fazer um trabalho. Formato: "Quando [situação], eu quero [motivação], para que [resultado]". Dimensões funcional, emocional, social. Concorrência = tudo que faz o mesmo trabalho, inclusive não fazer nada.

**Proposta de valor** — a promessa de resultado para o cliente, em uma linha, sem tecnologia. **Conceito de alto nível** — comparação que ancora ("o X para Y"). **Pitch** — dor como pergunta → entrega → credencial, ~20 s.

**Lean Canvas** — uma página com problema, alternativas, segmentos, early adopters, proposta de valor, solução, canais, receita, custos, métricas e vantagem injusta. Cada bloco: fato ou hipótese.

**Vantagem injusta** — o que não se copia nem se compra: histórico, rede, reputação, dados exclusivos, acesso. Preço, qualidade e atendimento não contam.

**Momento aha** — o instante em que o usuário percebe, por conta própria, que o produto resolve a dor dele. É uma experiência, não uma tela.

**Momento wow** — a surpresa que supera a expectativa e faz a pessoa contar para alguém; motor de indicação. Vem depois do aha.

**Tempo até o valor (TTV)** — passos e minutos do cadastro até o aha.

**Ativação** — % de novos usuários que chegam ao aha num período.

**Product-led growth (PLG)** — o produto atrai, converte e expande: experimentar → valor sozinho → pagar. Bom com TTV curto, decisor = usuário, ticket baixo/médio, configuração autônoma. Ruim quando a venda exige reunião, comitê ou implantação. Híbrido é comum.

**Modelos de entrada** — freemium (grátis com limite), trial (tempo), trial reverso (tudo liberado, cai para grátis), demo interativa sem cadastro.

**PQL (product-qualified lead)** — usuário que fez as ações que costumam preceder o pagamento.

**Loop de crescimento** — o uso gera novos usuários (convite de time, resultado compartilhado com a marca do produto).

**North Star** — a métrica única que sobe quando o cliente recebe valor e a empresa cresce. Mede valor entregue, não vaidade (cadastros, downloads). Tem alvo e prazo.

**Métricas de entrada** — 2–4 números que o time move toda semana e que empurram a North Star.

**Experimento** — hipótese → teste → critério de sucesso definido antes → prazo curto.
